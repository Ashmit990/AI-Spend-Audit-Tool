# AI Spend Audit Tool

A premium, interactive web application to audit, visualize, and optimize AI spend across major providers (OpenAI, Anthropic, Google Gemini, Cohere, etc.).

## 🚀 Getting Started

1. Clone the repository (once pushed).
2. Open `index.html` in any web browser to run the tool.

## 🛠️ Features

- **Spend Dashboard**: High-level KPIs and provider distribution charts.
- **Log Auditing**: Upload API logs to run automated cost reviews.
- **Cost Simulator**: Interactive calculators comparing model prices.
- **Optimization Suggestions**: Automated insights on how to reduce token costs.
